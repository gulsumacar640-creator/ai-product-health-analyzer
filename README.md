# 🥗 AI-Powered Food Label Analyzer

An AI-powered application that analyzes food product labels, evaluates nutritional information, and compares two products using artificial intelligence.

## 🌟 Features

- **Single Product Analysis:** Upload a food label image and receive an AI-powered analysis.
- **Health Score:** Get an estimated health score based on the information detected on the label.
- **Product Comparison:** Compare two products and examine their nutritional differences.
- **Image Upload:** Upload product label images directly through the application.

## 🛠️ Technologies

- Python
- Streamlit
- Google Gemini API
- Pillow (PIL)

## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/gulsumacar640-creator/ai-product-health-analyzer.git
   ```

2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Configure your Gemini API key using Streamlit secrets or an environment variable.

4. Run the application:

   ```bash
   streamlit run app.py
   ```

## ⚠️ Disclaimer

The health scores and analyses are approximate and based on the information detected from product labels. This application is intended for informational and educational purposes only and should not replace professional nutritional or medical advice.
